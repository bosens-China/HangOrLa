# 由航到拉

用图片制作等级榜单。等级行提供评价刻度，图片也可以放在两行之间，表达介于两个等级之间的评价。看板使用 HTML，面向台式机和笔记本浏览器，采用单一浅色主题。

网站图标采用黑白极简的纯矢量 SVG：深色圆角方底搭配三条逐级缩短的白线，表达排行，便于在浏览器标签页辨识。

## 菜单

右侧细条显示齿轮图标，在悬停或键盘聚焦时变明显。点击可以打开项目介绍、GitHub 仓库或用法与设置。

## 首次体验与清空

- 同一浏览器首次访问会展示内置美食图卡组成的示例排行，涵盖五个等级、跨行摆放和待摆放图库。示例无需联网，可直接编辑。
- 示例已展示的标记保存在浏览器本地，刷新或清空后不会自动恢复。图片仍为当前页面的临时状态，刷新前会提醒可能丢失图片。
- 右上角提供清空图标按钮，默认仅显示图标，悬停或键盘聚焦时展开“清空全部”文字，减少对榜单的遮挡。确认后移除榜单和图库中的所有图片，释放本地图片资源，保留等级与样式设置；空白状态下按钮禁用。

## 图库

图库保持在窗口底部，保留左右内边距。加号方块紧挨图库缩略图队列的右侧。缩略图超出宽度时，缩略图区域独立滚动，加号保持可见。点击加号可打开导入弹窗，通过本地上传、剪贴板或图片链接添加预览。新载入的图片默认勾选，确认时只把勾选的图片加入图库。

悬停图库图片时，右上角显示删除按钮，删除前需要确认。

## 图片摆放与等级样式

- 点击等级标签可以选择自动摆放的目标行，默认选中末行，界面不显示选中描边。点击图库缩略图后，图片从左往右找空位，超出可见宽度时继续向右摆放。跨线图片占用的空间会影响两侧等级行。
- 从图库拖入图片或在看板上移动图片时，默认纵向对齐目标行，靠近分隔线时可吸附到线上。看板上的图片上下小幅移动时保留实际落点，按住 Shift 可在任意距离下精确摆放。拖入发生重叠时，图片留在图库。看板内拖动发生重叠时，图片回到原位，同一等级行内的交换除外。
- 两张图片都完整位于同一等级行时，可以把其中一张拖到另一张上交换位置。
- 悬停榜单图片时，右上角显示移除按钮。点击后图片回到底部图库，可再次摆放。
- 等级行和底部图库按窗口高度自动布局。看板图片、图库缩略图和加号方块都与等级行同高。看板图片随窗口等比缩放，保留相对等级分界的位置。高度不足时可上下滚动榜单。删除某行时，占用该行空间的图片会回到图库。
- 调整等级顺序时，行内图片跟随所属等级移动；与重排范围相交的跨行图片回到图库，避免与移动后的图片重叠。
- 横向内容溢出时，悬停等级行或图库会显示细滚动条，键盘聚焦也会显示。等级行共用横向滚动位置，跨行图片随榜单一起移动。
- 每个等级提供三组独立样式设置：左侧标签背景、底部分隔线开关与颜色、标签文字颜色。背景只影响左侧标签，图片区域保持原来的背景。未手动指定文字颜色时，按背景自动选择深色或白色文字；手动文字颜色随等级设置保存在浏览器中。
- 默认使用黑色下边框，末行完整显示下边框。图片与单行对齐时会露出下边框，跨行的图片可以自然跨过分隔线。
- 设置面板宽度不超过窗口，较窄时全局控件可换行；每个等级的背景、分隔线和文字颜色纵向分组，避免控件挤压。
